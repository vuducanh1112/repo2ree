# Tutorials

Tutorials teach repo2ree through complete, guided experiences. Start here if
you have not authored or reviewed a Reproducible Execution Environment before.

- [Create your first REE](create-your-first-ree.md) — turn a small Python
  project into a built, tested, and sealed REE through the GUI.

These tutorials use one controlled path so that each new idea has a concrete
result. For goal-oriented instructions, use the
[how-to guides](../README.md#how-to-guides).
