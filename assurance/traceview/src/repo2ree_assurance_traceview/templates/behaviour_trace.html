Operations

Setup and the operations that produce evidence, in evidence order. Authoring between them is collapsed. Expand an entry for its run, dispatch, attempt, the rules it triggered and its largest spans.

Checked evidence: the API process journal (runs, allocations, dispatch), the REE's Git capture history (attempts, steps, REE state) and the persisted stores. Rule results come from repo2ree_assurance_checker.

Context only: OpenTelemetry spans, joined through the trace id the journal records carry: the provider's and workbench's spans join the control plane's trace. Only requests that led up to an operation (an upload's init and chunks) are matched by time, marked "by time".
